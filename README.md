# Pet Classifier

This repository contains a pet classification model built in a Jupyter Notebook.

## Dataset

The model uses the Oxford-IIIT Pet Dataset. 

Please download all the images for the dataset from the link below before using this model:

[The Oxford-IIIT Pet Dataset on Kaggle](https://www.kaggle.com/datasets/tanlikesmath/the-oxfordiiit-pet-dataset)

## Usage

1. Clone this repository.
2. Download the dataset from the link above and extract it.
3. Open `pet classifier.ipynb` in Jupyter Notebook or Google Colab and run the cells. Make sure to update any dataset paths in the notebook to point to your downloaded dataset location.
